One line roasting my fridge, in a single line — an entry for the
[One Line, One Laugh: Roast Your Fridge](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521?ref=qrg7fvky)
competition on [make.fun](https://make.fun/?ref=qrg7fvky).

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt`:

> I found a vegetable in the crisper drawer so old it had a retirement plan and a grudge.

87 characters. The crisper drawer is supposed to keep vegetables fresh —
instead it archived this one so long it earned a retirement plan, and it
holds a grudge for being forgotten. Run it locally with
`node main.ts /tmp/entry.txt` to see the exact output.
